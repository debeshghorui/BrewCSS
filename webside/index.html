01 Engine

Four steps, then a quiet stylesheet.

initBrew() scans immediately. After that it watches for added nodes and class changes. Pass { observe: false } when you only want one pass.

  1. 01

    Scan

    Walk the tree and collect elements that carry a brew-* class.

    scanDOM(document)

  2. 02

    Parse

    Split the class into a utility name and an optional value.

    brew-p-24 → p, 24

  3. 03

    Compile

    The registry turns that pair into a single CSS declaration.

    padding: 24px

  4. 04

    Register

    Insert one shared rule. The next element with the same class reuses it.

    .brew-p-24 { padding: 24px }

02 Rules

Values you can write by hand.

A bare number becomes pixels. Add a unit when you want one. Colors accept a short name, a -500 suffix, #rgb, #rrggbb, or a hex- prefix.

  • black
  • white
  • gray
  • gray-100
  • gray-900
  • red
  • blue
  • green
  • yellow
Class in, declaration out
Class Declaration
brew-p-10 padding: 10px
brew-m-1.5rem margin: 1.5rem
brew-m-50pct margin: 50%
brew-m--8 margin: -8px
brew-fs-2vh font-size: 2vh
brew-bg-blue-500 background-color: #3b82f6
brew-text-#fff color: #fff
brew-bg-hex-111827 background-color: #111827
brew-border-2 border: 2px solid #000000
brew-border-red border: 1px solid #ef4444
brew-center text-align: center

Length units: px rem em % vh vw vmin vmax pt. The pct suffix is a percent. A number on brew-border-* sets the width in black. A color name sets a 1px border in that color.

03 Setup

Install it, then call init.

initChai() is the same function as initBrew(). stopBrewObserver() disconnects the watcher.

npm

npm install @debeshghorui/brewcss

module

import { initBrew } from "@debeshghorui/brewcss";

initBrew();

CDN

The script also exposes window.initbrew, window.initChai, and window.initchai.

npm package GitHub jsDelivr build
